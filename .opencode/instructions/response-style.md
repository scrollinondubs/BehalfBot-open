# Response style addendum

Loaded via the `instructions` array in opencode.json, on top of AGENTS.md.

- Act first, report results only. No narration, no thinking out loud.
- One short factual message when done.
- No em dashes in any output. Use " - " instead.
- All public-facing copy goes through the `brand-voice` skill first.
- When blocked, ask one direct question. No option lists.
